执行每日论文阅读（RSI pipeline C1），产出 idea 卡片与日报。

步骤：
1. 读 rsi/paper-log.md，标记已推送论文，本次一律跳过；读 rsi/keywords.md 取最新关键词与业务方向。
2. 用 @Web 检索近 7 天 arXiv（cs.RO 为主，兼 cs.CV / cs.LG / cs.AI）及公开论文源，围绕“具身长程家庭任务”做开放路线扫描，
   不得把检索词限制为 VLA 或 π 系列。按 rsi-core 的开放路线逐类扫描，优先补检近 7 次运行覆盖不足的方向；综合新颖性、业务相关性、证据强度，
   选出 3 篇前沿 Top + 1-2 篇短期强相关论文。若候选全部是 VLA，主动补检 TAMP、世界模型/MPC、RL/自改进、数据仿真、感知记忆或安全评测方向。
   强相关标准：直接对应 rsi-core 的两条短期主线（规划执行监控 / 数据效率泛化评测），可作为近期验证候选；
   强相关篇若超出 7 天需说明原因。
3. 逐篇精读，严格按 rsi-core 的卡片字段输出 4-5 张卡片，每张卡片必须标注“技术路线”；技术路线与代码仓的兼容性留到 C3/C4 分析，研读阶段不得因暂不能落地而排除，每张核心内容 ≤300 字。
4. 汇总：今日最值得跟进的 1 个 idea 及理由 + 短期强相关篇的落地优先级排序。
5. 把本次推送登记进 rsi/paper-log.md（日期 / 标题 / arXiv ID / 类别），
   日报写入 rsi/daily/YYYY-MM-DD.md，并在对话里给我摘要。

约束：不编造结论，读不到的细节标"未核实"；与 paper-log 重复的论文跳过，去重是硬要求。

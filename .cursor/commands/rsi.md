建立并执行一个 RSI 闭环，让单点 idea 验证流程持续自我优化（RSI pipeline C8，建议跑通 C1-C7 后启用）。

工作流对象：<单点 idea 验证闭环：改 openpi 代码 → 小规模微调 → 固定评测 → 报告>
评测口径：<固定指标，用于判断这轮改动是否值得保留>
迭代预算：本轮最多尝试 <N> 次

闭环规则（三角色分工，在单 Agent 中按轮次模拟）：
1. Agent（提方案）：基于 rsi/experiments/experiment-tree.md 历史实验树与 idea 池提出下一步改动方案。
2. Optimizer（分配预算）：按历史收益与探索需求分配本轮尝试预算，决定先试哪个方案。
3. Evaluator（固定规则评测）：用同一评测口径判定结果，好则保留、差则回退，
   结果以"假设 / 改动 / 指标 / 失败原因"记入实验树。
4. 跨轮次保留有效改动：验证有效的改动沉淀进 rsi-core 规则或代码基线。
5. 每轮结束复盘：学到什么 / 哪些改动保留 / 下一轮预算如何分配。
6. 预算用尽即停，输出实验树摘要 + 迭代报告 rsi/experiments/YYYY-MM-DD-rsi-report.md。

约束：评测必须用固定规则，禁止自评通过；不得无限尝试；所有实验可追溯。

## 4. 失败模式归纳

> 以下均来自公开源明示陈述；凡为推断的条目已标注「推断」。

**F1 · 搜索密集任务耗尽时间预算（主瓶颈，#1 自述）**
榜首自述：hidden 评测相对开发 instance 的最大跌幅集中在 search-heavy 任务——目标物藏在遮挡处，时间预算被搜索消耗完。多数任务跌幅 < 0.2 Q，少数任务持平或提升。

**F2 · 组合泛化断崖（卫星榜量化最清楚）**
RoboCasa365 三 split 自 Atomic-Seen → Composite-Seen → Composite-Unseen 系统性塌陷：
- π0.5 基线：39.6% → 7.1% → **1.2%**
- 最强 VLA（minionx）：81.8% → 60.0% → 43.6%
- 最强 Agent（HexaShell 1.5）：91.1% → 85.0% → **80.0%**
单体 VLA 在未见组合上掉 ~38pp，Agent 类只掉 ~11pp。说明瓶颈不在原子技能，而在**任务级组合与排序**。

**F3 · 公开集 → 核验集的显著落差**
A²MEAS 论文自报「100 任务 BEHAVIOR 2026 public set」Q 0.6411 / 完整成功率 45.40%，而同队 verified 条目为 Q 0.4975 / 32.05%（Δ −0.144 Q / −13.4pp）。两数字可能分属不同 instance 集合（见 §1 口径未核实项），但差距远超评测噪声地板，**自报分数不能当作核验分数使用**。

**F4 · 评测噪声地板远大于多数文献声称的增益（可直接复用的方法学）**
同一策略在同一 4 个 instance 上重跑两次：ΔQ = +0.014 ± 0.021（95% CI [−0.027, +0.056]），ΔSR = +1.6 ± 2.3pp；单 instance 的均值 Q 可漂移达 0.073。
→ **ΔQ 落在约 ±0.06 内无法与运行噪声区分**。官网亦明示仿真非确定性，禁止跨 run / instance / task 挑最好结果。

**F5 · 推理设置不均匀迁移（反直觉项）**
同一论文的配对消融（基线 Q 0.402）：
- action-chunk 执行 horizon 26 → 13（即**加倍重规划频率**）：ΔQ **−0.165** ± 0.032，ΔSR −11.0pp，仿真步数 +752 → 明确有害
- horizon 26 → 30：n.s.
- playback 1.3× → 1×：ΔQ −0.042，ΔSR −3.8pp → 有害（1.3× 加速应保留）
- 去噪步数 20 → 10 / → 1：均 n.s. → **可降到 1 步省算力**
- overlap inpainting 开 → 关：n.s.
- advantage guidance 强度 1 → 2：ΔQ −0.035，ΔSR −4.0pp → 边缘有害；1 → 4：n.s.
- gripper snap 开 → 关：ΔSR −5.3pp → 边缘有害
- Best-of-N 1 → 4（无学习打分器）：n.s. → 裸 best-of-N 不work
- 渲染分辨率 native → 224：n.s.

**F6 · 仿真器接口级陷阱**
夹爪释放：OmniGibson 仅在 gripper 指令**恰好为 1.0** 时释放物体，策略输出常停在略低于 1.0 → 机器人悬在垃圾桶上方「反复接近但不放手」。修法是把 > 0.9 的开合指令投影到 1.0（gripper snap）。影响集中在需反复抓放的任务。

**F7 · 策略内部状态在重启时必须一并恢复**
数据采集消融：从仿真快照重启失败 episode 可省 29–43% 仿真步且不降成功率；但**不恢复策略的 stage belief** 则 ΔQ −0.053、ΔSR −5.1pp；base 位姿扰动 0.15 m / 15° 亦有小幅损失（ΔQ −0.036）。
→ 长程任务中「任务阶段信念」是真实状态的一部分，不是可丢弃的缓存。

**F8 · 工程性失败直接吃掉整条 rollout（规则层）**
超时或崩溃的 rollout 直接计 0 分；首次 query 有 600 秒单独额度（含 checkpoint 加载 / GPU 搬运 / warm-up），失败不补；断线最多重连 3 次且不重置预算；每个 rollout 的计费预算为 max_steps 秒，并被摊分共享仿真步时间。自报分区中 20/51 条 Q < 0.10、多条 ≈ 0.0，**推断**其中相当部分属于此类工程失败而非策略能力不足。

**F9 · 示范长度极度不均导致采样偏置**
最长 / 最短任务的平均示范长度差 12 倍；若按帧均匀采样，长任务被抽到的频率是短任务的 12 倍。公开做法是按示范总长的 0.35 次幂加权，把 12 倍长度差压到 2.4 倍权重差。

## 6. 对「冲击 #1」的直接含义（仅记录信号，不含实施动作）

1. **目标线已知**：verified #1 = Q 0.6828 / SR 48.2%；verified Top-5 门槛 ≈ Q 0.495；自报分区最高 0.5143。
2. **基线天花板已知**：2025 冠军全套改装 + 自采 rollout 飞轮 + 8×B200 ≈ Q 0.39。纯 VLA 路线与 #1 之间约有 0.29 Q 的结构性差距，不像是靠继续加数据/算力能补上的。
3. **最高杠杆的三条**：(a) 可执行结构 + 代码化自改进 + 按任务路由（唯一两榜登顶族）；(b) WAM 式联合视频-动作建模（未见组合 split 上最强，但细节未公开）；(c) 纠错码 / 失败恢复 adapter（有论文 + 开源承诺，可验证性最好）。
4. **必须先建的评测纪律**：评测噪声地板 ΔQ ≈ ±0.06，低于此的改进不可报为增益；禁止跨 run/instance/task 挑结果；长程任务须同时报端到端完成率与 subgoal 级 Q（与 rsi-core 硬规则 6、8 一致）。
5. **低成本先验**（来自已公开消融，均可在 openpi 侧直接核对）：保持 action-chunk 执行 horizon ≥ 26（勿加密重规划）；保留 1.3× playback 加速；去噪步数可降至 1 步省算力；overlap inpainting 可关；advantage guidance 强度勿超 1；保留 gripper snap；快照重启须一并恢复 stage belief；按示范总长 0.35 次幂做任务采样加权。
